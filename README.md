# AEGIS NEXUS

## Project Overview
AEGIS NEXUS is a network monitoring and threat detection project designed to monitor network activity and identify suspicious behavior. It provides a dashboard to visualize monitoring information and helps users understand potential network security threats.

## Objectives
- Monitor network activity.
- Identify suspicious network behavior.
- Display monitoring information through a dashboard.
- Provide alerts for detected anomalies.
- Improve network visibility.

## Features
- Interactive dashboard
- Network activity monitoring
- Suspicious activity detection
- Alert notifications
- Data visualization

## Technologies Used
- Python
- Streamlit
- Data Analysis
- Network Monitoring

## Installation

1. Clone the repository:

   git clone https://github.com/Sarmathi141/Aegius-Nexus.git

2. Navigate to the project folder.

3. Install the required dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py
